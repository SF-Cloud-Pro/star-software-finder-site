# STAR Software Finder: SDR dashboard (website copy)

A static copy of the SDR performance dashboard.

- `index.html` is the page. It has no build step.
- `data.json` holds the scores. It is refreshed from the team workbook each morning.

This repository is public on purpose. The SDR names and scores in `data.json` can be read by anyone with the link. The dashboard code lives in a separate private repository.
